## Quick Highlights

- **Visual Contrast**: Supports modern dark/light themes meeting 4.5:1 text contrast minimums.
- **Keyboard Navigation**: Full tab navigation with visible focus rings and skip-to-content links.
- **Screen Reader Support**: Semantic HTML5 landmark tags (`<main>`, `<nav>`, `<aside>`, `<header>`) and accessible ARIA attributes.
- **Reporting Barriers**: Open an issue using the [Accessibility Issue Form](https://github.com/darkpyramid-org/Dev-Studio-Full/issues/new?template=accessibility.yml).
